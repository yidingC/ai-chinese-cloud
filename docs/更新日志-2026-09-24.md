# 学生端互动题型 · 更新日志（2026-09-24）

> 主线：课堂页从"一关一题"升级成**轮次制**——一轮可以跨页跑多道题，按轮记账、按轮计时，三个轮次不再互相锁；顺手把"课堂互动"的产品口径写成 PRD 入库。
> 范围：学生端手机原型（课堂页 + 题型页 + 公共件）；后台 `admin/**` 未动。本地预览：`npm run dev` → `http://127.0.0.1:5173/`
> 说明：本页记的是 9-22 那次推送之后、到这轮收工的全部改动。

## 一、课堂页：轮次制上线

- **三个轮次同时开放**：开课后每一轮都能直接点，不再"做完上一关才解锁下一关"（顺序锁 `unlockedBefore` 删掉）；卡片状态只剩 `todo / done`（加上未开课的 `locked`）。
- 卡片右上角加「LESSON 1」小胶囊，数字来自课程数据 `lesson.no`——以后上第二课只改数据，页面里不写死。
- 卡片上那两行改成**"这一轮练什么"**（`title` / `subtitle`，教研填）：不再回落到题型名，哪一行空着就整行不显示。
- 卡面右下角那张**图形撤掉**：`LEVEL_CARDS` 只剩"题型 → 页面文件名"这一处对照表（`art` 字段和通用图形一起删）。以后加题型只改这一处。
- 速度榜那颗 ⚡ 的读屏文案从"看第 N 关的速度榜"改成"看第 N 轮的速度榜"（卡片统一叫"轮"）。
- 窄屏（≤360px）顶部状态条的排布修了一次。

## 二、第 1 轮样板：快速选择变成"一页 3 题"的一轮

- 一页里循环 3 道题（`QUESTION` → `QUESTIONS`）；题干上方一行进度：「第 2 题 / 共 3 题」＋三个小点（做完绿、当前紫、没做灰）。
- 底部按钮三态：没选＝灰【提交 / Kirim】禁用 → 选了＝紫【提交 / Kirim】→ **答完且不是最后一题**＝紫【下一题 / Lanjut】→ 最后一题答完＝灰【已提交 / Terkirim】。
- **整轮只记一条账**：最后一题提交那一刻调一次 `finish({ correct: 整轮有没有答错过, seconds: 整轮用时 })`；用时从进第 1 题算起，跨题不重置。
- 「再练一次 / ↻再做一次」＝**整轮重做**（回第 1 题、重新计时）；中途返回课堂什么都不写，下次进来从第 1 题重新计时。
- `shared/activity-bridge.js`：同一个 slot 再次写入时**保留第一次的 `seconds` / `completedAt`**，其余字段用新的——「再做一次」不会把速度榜的"我的用时"改掉。

## 三、跨页混题型一轮（试点：第 3 轮）

- 新增 **`round-content.js`**（跟 `classroom-course.js` 并排）：一节课的题目数据（试点版，以后由后台生成）。第 3 轮＝快速选择 → 听音选词 → 连线配对 → 补全句子（共 4 题），每道题自带 `type` 和内容。
- 新增 **`shared/round-flow.js`**：一轮的事全归它——读 URL（`slot` / `q` / `total`）判定是不是轮内、画进度行、按钮三态、拼"下一题"链接（题型 → 页面文件名查 `shared/activity-types.js` 那张表）、整轮计时、最后一题记账 + 1.4 秒后轮末弹窗（返回课堂 / ↻再做一次）。
- 整轮计时存 localStorage（`ai-chinese-cloud-round-start-v1`，形如 `{ "3": { startedAt, total, missed } }`）：进第 1 题那刻开始；中途点返回课堂会清掉（不记账）；超过 10 分钟当过期重来；`missed` 记"这一轮有没有答错过"，决定轮末弹窗走哪档句池。
- 课堂页拼链接时带上 `q=1&total=<questionCount>`：`classroom-course.js` 新增字段 `questionCount`（不写＝这一页就是这道题）。
- **不是轮内（题型体验、单独打开）→ 一律老行为**，一个字都不变。

## 四、题型页接轮（18 页）

- 两套收尾口径：**有提交键的页**——按钮原地从【提交】变【下一题 / Lanjut】，最后一题变【已提交 / Terkirim】；**没提交键的页**——卡片/板子下面一颗**常驻**的【下一题 / Lanjut】，进场就摆着（灰、点不动），本题做完变紫可点。
- 已接：
  - 有提交键 11 页：快速选择、听音选词、补全句子、看图单选、情景选择、情景对话、找错改错、组句拼词、分类归组、句子排序、课堂投票；
  - 没提交键 7 页：拼音匹配（配满三组自己收尾）、记忆翻牌、图片—词语连线、连线配对（`match.html`，接在 `app.js` 的 `initMatch` 里）、跟读模仿、看图说话、开放问答。
- 轮内三条"不"：**不记账、不弹本页的完成弹窗、不自动跳页**（开放问答原来是"记账后 2.6 秒自动回课堂"，轮内改成不跳——跳转和结算都归轮末）。
- 语音/开放三页（跟读模仿、看图说话、开放问答）：轮内出结果后**重录键停用**（变灰、点不动），想重练等轮末弹窗的「再做一次」。
- 进度行样式提到 `styles.css`（`.round-progress / -dots / -text`）四批页面共用一份；不是轮内时整块不出现。
- 各页自己的小差异一律保留：排序的【重置】键提交后仍禁用、情景选择进页打乱选项、分类归组提交后把放错的词移回待归类区、拼字组词字块打乱、投票没有对错（轮内 `afterAnswer` 恒传 true）、每题只判一次、读屏播报口径不变。

## 七、怎么快速看

- **整轮**：课堂页点第 3 轮「问候和时间」→ 第 1 题快速选择（1 / 4）→ 答完点【下一题】→ 听音选词（2 / 4）→ 连线配对（3 / 4，连完 4 对才出现【下一题】）→ 补全句子（4 / 4）→ 1.4 秒后轮末弹窗 →「返回课堂」。
- **记账**：回到课堂页——第 3 轮变绿勾、+5 分、点亮一颗星；⚡速度榜里"我"的用时＝跨四页的总秒数；再点「再做一次」跑完一轮，用时不变。
- **老行为**：任意题型页单独打开（题型体验）——没有进度行、没有【下一题】，做完照旧自动弹窗。
