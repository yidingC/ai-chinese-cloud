# 学生端互动题型 · 交付说明（2026-09）

**一句话**：学生端四批共 16 个可复用互动题型已完成（第四批 4 个为「占位版」），加上原有 2 个（连线配对、记忆翻牌）共 18 个，全部接入统一入口「题型体验」。只动学生端，未动 `admin/**`。

## 一、题型清单（key｜玩法）
- 快速选择（choice）｜读题点选，提交后立即判分
- 句子排序（order）｜多邻国式：点词块排进上方「答案行」，可退回重排
- 补全句子（fill）｜从词库点选词语填空
- 课堂投票（poll）｜不计分，老师看统计
- 看图单选（picture）｜看一张图，从选项里选出正确的词（图片先用 emoji 占位）
- 图片—词语连线（picture-match）｜点左右两边的图和词，配对成功即锁定（点选式，不画线）
- 情景选择（situation）｜看场景，选出这个场合里最得体的说法
- 对话补全（dialogue）｜看上一句，选合适的下一句填进对话气泡
- 拼音—汉字—含义匹配（pinyin-match）｜看拼音选汉字，再选它的意思，一组一组配起来（闯关式）
- 分类归组（category）｜把词语一个个放进正确的类别，提交后看结果
- 拼字/组词（word-build）｜点字块，把词语拼进空格
- 找错误/改错（correction）｜读句子，点出用错的那个词，看正确说法
- 听音选图/选词（listening）｜占位版：播放是假流程，判分是真的
- 跟读模仿（read-aloud）｜占位版：听一遍、跟着读，开口说了就算完成（假波形，不碰麦克风）
- 看图说话（picture-talk）｜占位版：看一张图说一句话，说完给一句鼓励 + 参考答案
- 开放问答（open-qa）｜占位版：回答一个开放问题，说完给一句鼓励 + 句型提示
- 连线配对（match）｜原有题型，保留
- 记忆翻牌（memory）｜原有题型，保留

## 二、怎么体验（本地预览）
1. 打开 `/classroom.html`，点右下角紫色「题型体验」按钮 → 任选题型
2. 单独打开：`/interaction-<type>.html?type=<type>`
3. 课堂模式（模拟老师发题到学生手机）：`/interaction-<type>.html?type=<type>&mode=class&slot=1`，完成后弹反馈弹窗，点【返回课堂】回课堂页并解锁下一题

## 八、反馈句池口径（2026-09-21 追加）

- 档案：`shared/feedback-copy.js`；用法 `AICloudFeedbackCopy.draw(key, options)`，返回 `{ zh, id, emoji }`——表情跟着文案成对抽，一次作答只抽一次，同一句不连续重复。
- 池子：`correct` 通用夸夸（所有题型）｜`correctFirstTry` 第一次就答对（🏆）｜`wrong` 答错（💪）｜`pair` 配对专属（`{ perfect }` 决定专属句进不进候选）。档位名、弹窗图标与配色都不变，差别的只是抽到哪一句。
- **单题页**（一屏一道题、一次作答只判一个东西）：用 `draw("correctFirstTry", { single: true })` 走**单题池**，句子里不出现"全 / 处 / 都"这类只在多件题成立的字。已接 6 个：听音选词（listening）、快速选择（choice）、看图选择（picture）、找错改错（correction）、情景选择（situation）、情景对话（dialogue）。
- **多件题页面不动**：不传 `single`，仍走多件池，能抽到「一次就全对！」「一处都没错！」——补全句子（3 个空）、拼字/组词（多个格）、句子排序（整句多个位置）、分类归组，以及配对类（配对 / 记忆翻牌 / 看图配对 / 拼音配对，走 `pair` 池）。
- 单题池定稿（中文｜印尼语，均以「！」结尾、不超过 6 字）：
  1. 一次就对！｜Sekali coba, benar!
  2. 一下就答对！｜Langsung benar!
  3. 真准！｜Tepat sekali!
  4. 一眼就对！｜Sekali lihat, tepat!

## 九、对勾（✓）规格（2026-09-21 追加）

- **全站只有一支笔**：`styles.css` 的 `--check-pen`（24 viewBox / 圆头圆尾 / stroke 3.6，和课堂页 `app.js` 的图标同一支；白勾，当背景图能画、当 mask 能换色）。要改笔形只改这一处，**各页不许自创第二种勾**。
- **① 圆徽章 = 22px 圆 ＋ 18px 笔**：
  `width: 22px; height: 22px; border-radius: 50%; background: <本页的正解色> var(--check-pen) center / 18px 18px no-repeat;`
  绿圆用各页自己的正解色（多数是 `--answer-correct`，看图配对是 `--pm-correct`）；贴内角还是外扩、弹出动画都保持各页原样。
  - 已统一（12 处）：听音选词（基准）、快速选择、看图配对、连线配对、拼音选词（选项 ＋ 槽）、补全句子、看图选择、情景选择、情景对话、句子排序、拼字组词、课堂投票。
  - 两处"语义不是答对"的**只换笔形、保留自己的颜色**：课堂投票 = 紫色（已选中）、拼音选词的槽 = 绿（这格填好了）。
- **② 行内勾 = 同一支笔的 15px**：结果条里「✓ 答对了！」那颗——
  `width: 15px; height: 15px; font-size: 0; background: currentColor; mask: var(--check-pen) center / contain no-repeat;`
  颜色跟着那一行的字色；行内尺寸只在 14–16px 里取 **15px**，全站一致。
  - 已统一（7 处）：快速选择、补全句子、拼字组词、看图选择、情景选择、情景对话、找错改错。
- **答对的绿只有一套**（2026-09-22 追加）：`--answer-correct: #1fbf8f` ＋ 底色 `--answer-correct-fill: #e8fbf3`，配对色 `--answer-correct-edge: #a9e8d3`、结果条深字 `--answer-correct-text: #0f8f68`。
  `styles.css` 里的 `--success: #22ad83` 是课堂页／平台自己的颜色（进度徽标、连线指示等），**题型页不许拿它当答对色**。
  已按这套收口：句子排序（`.order-tile-mark` 的勾圆、`.order-answer-word.is-correct`）和分类归组（`.category-chip.is-correct`、`.category-feedback.is-correct`）此前借用 `--success`，现已各自在本页 `:root` 立了上面这套变量。
- 以后新页面照抄上面两条，**不要自己写 `content: "✓"`**。
