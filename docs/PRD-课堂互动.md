| 1 | **功能点名称**：首页入口：课堂互动<br>**功能描述**：首页「常用功能」里的「课堂互动」磁贴，是学生进入课堂互动的入口；按本节课的阶段开放——课前不可进、课中开放、课后可回看与重做、次日关闭。<br>**主流程**：首页 → 点「课堂互动」 → 判断课节阶段 → 可进入：进课堂页；不可进入：屏幕提示，留在首页。<br>**规则**：<br>• 阶段由课节时间驱动，磁贴角标同步显示：未开始 / 课中 / 可回看 / 已结束；<br>• 课前（未开始）：不可进入，点按提示「课堂互动将在今天 10:00 开课后开放」（时间按课节配置）；<br>• 课中：可进入（正常答题，节奏由老师口头控制）；<br>• 课后（当天 23:59 前）：可进入，课上没做完的可以继续完成、已完成的轮次可以重做；<br>• 次日（已结束）：不可进入，点按提示「今天的课堂互动已经结束」；<br>• 兜底：在课堂页内跨过时间点（如停留到次日）时，点轮次卡片同样给提示、不进入。<br>**原型图**：<br>![首页入口 · 课前 / 课中 / 课后](prd-strip-home-a.png)<br>【首页 · 课前】｜【首页 · 课中】｜【首页 · 课后】<br>![首页入口 · 次日](prd-strip-home-b.png)<br>【首页 · 次日】<br>**流程图**：<br>![首页入口 · 流程图](prd-flow-entry.png) |
| 2 | **功能点名称**：课堂页（轮次列表）<br>**功能描述**：学生进入课堂后的主页。顶部是本节课的状态条（课次与课节名、星星、得分排名）；主体是本节课的互动轮次列表，点任意一轮进入答题，答完整轮回到本页。<br>**主流程**：进入课堂 → 看到本节课全部轮次卡片（默认全部可点）→ 按老师口令点开某一轮 → 轮内答题 → 答完整轮回到本页 → 该轮卡片显示完成。<br>**规则**：<br>• 顶部状态条：课次行「第一课 · 嗨！你好！」（原型图待更新）＋ 星星槽（个数＝本节课轮数，做完一轮亮一颗）＋ 🏆 得分排名（「等你上榜」／「12 / 40 · 5 分」）；口径见功能点 5；<br>• 轮次卡片：一张卡 = 一轮互动（1~N 道题，题型可混）；卡面是序号、主题（中文 + 印尼语）、同班完成人数（x / 40）、右上角 ⚡（速度榜，见功能点 6）、右侧是播放图标 ▶；做完后序号变绿勾、右侧变重做图标 ↻；卡片上不出现星星与得分（都在顶部状态条）；<br>• 轮次主题由老师在后台填写：不填则整行不显示；过长时卡片上省略号、后台可见全文；<br>• 所有轮次默认开放，点卡片进该轮第 1 题（同时开始整轮计时，口径见功能点 6）；已完成的轮次再点 = 重做整轮（见功能点 4）；什么时候做哪一轮由老师口令控制，系统不做发放；<br>• 卡片按阶梯错动排布：轮数多时左右错开（如 5 轮）；<br>• 本节课全部轮次完成后，回到本页会出「全部完成」弹窗（全屏庆祝；视觉以 UI 稿为准）：只弹一次、只能点「Mantap!」关闭（点弹窗外不关）；关闭后停在全完成状态（全部绿勾、满星、总分）。<br>**原型图**：<br>![课堂页 · 初始 / 一轮 / 三轮](prd-strip-class-a.png)<br>【课堂页 · 初始】｜【一轮已完成】｜【三轮已完成】<br>![课堂页 · 全部完成弹窗](prd-strip-class-b.png)<br>【全部完成弹窗】（关闭后停在三轮完成这一屏）<br>**流程图**：<br>![课堂页 · 流程图](prd-flow-classroom.png) |
| 3 | **功能点名称**：轮内答题<br>**功能描述**：一轮互动内部的连续答题流程。学生逐题作答，每题做完后看到这道题的反馈（对 / 错，含正确答案；语音题只有一句鼓励）；非最后一题点「下一题」继续，答完最后一题进入整轮完成弹窗。一轮可包含 1~N 道题，题型可混。<br>**主流程**：进入该轮第 1 题 → 作答 → 提交 → 答题反馈 → 点「下一题」→ 第 2 题 → …… → 第 N 题 → 提交 → 整轮完成弹窗（功能点 4）。<br>**规则**：<br>• 轮内连续答题、不返回课堂页，只有答完整轮才回课堂；<br>• 非最后一题：提交后按钮变为「下一题（Lanjut）」，手动点击继续（不自动跳转）；<br>• 最后一题：提交后按钮变为「已提交（Terkirim）」不可再点，短暂停顿后进入整轮完成弹窗；<br>• 单题轮（一轮只有一道题）：提交后直接进入整轮完成弹窗，没有「下一题」环节；<br>• 题目进度：多题轮显示「第 x / N 题」；<br>• 判定类题型每题只判一次、不提供单题重做，想重做走整轮「再做一次」（功能点 4）；<br>• 语音类题型（跟读模仿 / 看图说话 / 开放问答）：开口就算完成、不打分，口径见功能点 11；<br>• 课堂投票：无对错，照常参与轮内流程，不影响本轮计分；<br>• 中途退出不保存进度：下次进入从第 1 题重新开始，整轮重新计时。<br>**原型图**：<br>![轮内答题 · 逐题与反馈](prd-strip-round-a.png)<br>【轮内第 1 题】｜【答题反馈 · 正确】｜【答题反馈 · 错误】<br>![轮内答题 · 收尾](prd-strip-round-b.png)<br>【最后一题 · 已提交】｜【整轮完成弹窗】<br>**流程图**：<br>![轮内答题 · 流程图](prd-flow-round.png) |
| 4 | **功能点名称**：整轮完成与「再做一次」<br>**功能描述**：一轮全部题目答完后出现的整轮完成弹窗：展示完成祝贺（表情 + 中文 + 印尼语），提供「返回课堂」「再做一次」两个操作；点弹窗外空白处可关闭弹窗、回看最后一题。<br>**主流程**：最后一题提交 → 答题反馈 → 整轮完成弹窗 →「返回课堂」（回轮次列表）｜「再做一次」（回第 1 题、整轮重做）｜点弹窗外空白处（关掉弹窗、回看最后一题）。<br>**规则**：<br>• 弹窗内容：全屏遮罩 + 居中卡片；1 条祝贺语（表情徽章 + 中文标题 + 印尼语副题）；两个按钮（都带印尼语副行）：「返回课堂 / Kembali ke kelas」「再做一次 / Coba lagi」；不显示得分、星星、用时；视觉以 UI 稿为准；<br>• 弹出时机：最后一题提交后，先照常显示本题的答题反馈，约 1 秒后弹窗才出现；弹窗以遮罩形式盖在题目页上层，本题反馈仍在（关掉弹窗即可看到）；<br>• 祝贺语规则：按本轮有没有答错分两档（全对档 / 有答错档）；每次弹出时随机抽 1 条——同一句不连着重复，重做后再次完成时重新抽；候选清单见文末「附｜整轮完成弹窗 · 祝贺语候选清单」（全对 4 条 / 有答错 6 条）；<br>• 按钮去向：「返回课堂」回课堂页轮次列表；「再做一次」回第 1 题、整轮重做（不是只重做最后一题）；重做后再次答完整轮仍会出弹窗（可继续重做、或返回课堂）；重做的计分与用时口径见功能点 5 / 6；<br>• 关闭与回看：点弹窗外空白处可关闭弹窗；关掉后停在最后一题（已提交状态，可回看题目与对错），从那里点左上角返回键回课堂页；<br>• 成绩记录：本轮成绩在最后一题提交后即已记录——无论点弹窗按钮还是点空白处关闭，都不影响；重做到一半退出不影响第一次的完成状态与成绩，下次进入该轮从第 1 题重新开始；<br>• 「返回课堂」后该轮卡片显示完成（序号变绿勾、右侧变重做图标 ↻），仍可再次进入（重做整轮）。<br>**原型图**：<br>![整轮完成弹窗与两个去向](prd-strip-finish.png)<br>【整轮完成弹窗】｜【点掉弹窗后 · 回看最后一题】｜【再做一次 · 回到第 1 题】<br>**流程图**：<br>![整轮完成 · 流程图](prd-flow-finish.png) |
| 5 | **功能点名称**：计分与星星<br>**功能描述**：一轮完成后的结算，以及课堂页顶部状态条上的星星槽与得分排名。<br>**主流程**：完成一轮 → 结算（+5 分、+1 颗星）→ 回到课堂页，状态条更新星星与总分（名次随之刷新）。<br>**规则**：<br>• 星星：一轮完成得 1 颗，重做不重复点亮；<br>• 得分：一轮完成 +5 分，不看题数、不看对错（2026-09-24 定）；重做不重复计分；课堂总分 = 各轮求和（满分 = 轮数 × 5，如 3 轮满分 15 分）；<br>• 名次：按课堂总分排名（同分并列）；<br>• 课堂投票不影响计分：含投票的轮次照样 +5 分 + 1 颗星；<br>• 整轮用时的口径与速度榜排名见功能点 6。<br>**原型图**：<br>![课堂页 · 星星与名次行](prd-strip-score-b.png)<br>【课堂页 · 两轮完成（星星与名次行）】<br>**流程图**：—（纯规则、无分支，不单独画图） |
