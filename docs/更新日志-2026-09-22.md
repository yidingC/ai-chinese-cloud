## 一、结果条 → "从卡片底下滑出的回执条"（14 页一套）

- 样板先在**快速选择** `.choice-feedback`、**补全句子** `.fill-feedback`、**句子排序** `.order-feedback` 三页立起来；本轮铺到其余 8 个判分页（听音选词 `.listening-receipt`、看图单选、情景选择、情景对话、找错改错、组句拼词、分类归组、拼音匹配）和 3 个语音页的学习卡（跟读模仿 `.read-aloud-result`、看图说话 `.picture-talk-result`、开放问答 `.openqa-result`）。
- 三条硬规则：条是卡片的**下一层兄弟**（卡片 `position: relative; z-index: 1`，压住条最上面 13px）；`top: calc(100% - 13px); right/left: 0`；出场从下往上滑 30px 落位（0.28s）。卡片和容器都**不加 `overflow: hidden`**（会把滑出来的条切掉）。
- 逐页实测（390 与 320 各一遍）：**条顶边 = 卡底 − 13px**、条宽 = 卡宽、**出条前后页面总高度不变**。提交态里卡片自身内容有重排的几页（情景选择、情景对话、组句拼词、分类归组），按钮位置本来就会动——用改前样式复跑过，位移数值一模一样，不是这轮带来的。
- 底色：答对 `#d4f3e9`；答错按页面语义走——中性紫 `#d9ceff`（条里装的是正确答案、不是错误提示的页）、情景对话保持自己的粉 `#fbd4d7`、听音选词与语音三页只报事实，也用中性紫。
- 条里只换外壳：`-title / -sentence / -translation / -answer / -copy` 的**文案、字号、字色、字重、行高、行内小勾逐页比对过，一处没动**（用改前样式注入后跑同一套操作做的对照）。
- 矮屏退路：出条后 `scrollIntoView({ block: "nearest" })`，等 0.28s 动画落定再量一次，只有条被屏幕下沿裁掉才补滚最小距离——常见屏（≥700 高）页面不动。
- 拼音匹配这页卡片下面还有一条"已配好的组合"槽位行：回执条滑出时压在它上面（容器 `.py-receipt-stage` 抬了一层），不然槽位的灰底和条的字会互相透出来。
- 情景选择页 `.page-content` 底部留白 150 → 190px，和其它页对齐。

## 二、答对的绿只有一套 + 回执条绿退浅一档

- 口径（已写进《交付说明》第九节）：`--answer-correct: #1fbf8f` ＋ 底色 `--answer-correct-fill: #e8fbf3`、配对 `--answer-correct-edge: #a9e8d3`、结果条深字 `--answer-correct-text: #0f8f68`。
- 句子排序和分类归组此前没有这套变量、只能借全站的 `--success: #22ad83`（老绿），于是全站出现过"差一点点的两个绿"——现在两页各自在本页 `:root` 立了上面这套。`--success` 归课堂页／平台用（进度徽标、连线指示等），**题型页不许拿它当答对色**。
- 回执条答对底色从 `#c7efe3` 退浅一档到 **`#d4f3e9`**（9 个文件、9 行）。理由：条是从卡片底下滑出来的"一张纸"，比块面用的绿再轻一点，不抢卡片里的内容。

## 三、对勾（✓）全站只有一支笔

- `styles.css` 立了 `--check-pen`（24 viewBox／圆头圆尾／stroke 3.6，和课堂页 `app.js` 的 `CHECK_ICON` 同一支笔）。要改笔形只改这一处，**各页不许自创第二种勾**。
- 用法一：**圆徽章 = 22px 圆 ＋ 18px 白勾**，`background: <本页正解色> var(--check-pen) center / 18px 18px no-repeat`。已统一 12 处：听音选词（基准）、快速选择、看图配对、连线配对、拼音选词（选项 ＋ 槽）、补全句子、看图选择、情景选择、情景对话、句子排序、拼字组词、课堂投票。
- 用法二：**行内小勾 = 同一支笔的 15px**，`background: currentColor; mask: var(--check-pen) …`，颜色跟着那一行的字色。已统一 7 处：快速选择、补全句子、拼字组词、看图选择、情景选择、情景对话、找错改错。
- 两处"语义不是答对"的**只换笔形、保留自己的颜色**：课堂投票那颗意思是"已选中"（紫）、拼音选词的槽意思是"这格填好了"（绿）。
- 顺手清理：`styles.css` 里已被各页覆盖的 `.match-item.correct::after` 死代码删掉；句子排序的 `.order-tile-mark` 和拼字组词的槽位徽章不再往元素里塞 "✓" 文字（改用同一张背景图）。

## 四、答对句池拆成"单题 / 多件题"两套

- 现场：一屏只有一道题的页面抽到「一次就全对！」「一处都没错！」——学生明明只做了一道题（实测抽 2000 次有 67% 会抽到这两句）。
- `shared/feedback-copy.js` 现在把 `correctFirstTry` 分两个池：**多件题池**（原来那三句原样保留）和**单题池** `correctFirstTrySingle`（4 句，中文＋印尼语成对、都带 🏆）：
  1. 一次就对！｜Sekali coba, benar!
  2. 一下就答对！｜Langsung benar!
  3. 真准！｜Tepat sekali!
  4. 一眼就对！｜Sekali lihat, tepat!
- 调用侧加开关：`draw("correctFirstTry", { single: true })` 走单题池；**不传 `single` 仍走多件题池**，所以多件题页面一行都没改。
- 已接 6 个"一屏一道题"的页面：听音选词、快速选择、看图选择、找错改错、情景选择、情景对话。多件题页面（补全句子、拼字/组词、句子排序、分类归组，以及配对类）不动——它们抽到「一次就全对！」是对的。
- 单题池里不出现"全／处／都"这类只在多件题成立的字；「完美！」仍留在多件池，两池不重复。抽句"不连续重复"的逻辑没动，档位名和 🏆 图标都没改。

## 五、语音三页结果形态定稿（仍然不打分）

- 三页统一后的样子：
  - 去掉假波形；按住时按钮只换红点，不跳柱子。
  - 按钮视觉上**只剩麦克风图标，名字落在 `aria-label` 上**（否则用屏幕朗读的学生会遇到一个没名字的按钮）；结果态那颗原地换成安静款白按钮，按下去才重录（重录只算练习，不重复记账）。
  - 贴底动作区那行小字是状态的**唯一可见反馈**，四态四句（待作答／正在听／识别中／再来一次），全是换文案不是藏起来。
  - 结果（跟读的回执条、看图说话与开放问答的学习卡）**从卡片下沿滑出来**，不再从下方弹上来；只放"一句鼓励 ＋ 能带走的内容"，不给分数、不给星级——录音本身就是交卷。
- 开放问答这页动得最多：题干卡只留问题（中文 ＋ 印尼语）和一条插画带（三个词的意思直接画出来，图上三个图形和下面三列小词一一对齐）；图下小词只留汉字 ＋ 拼音（意思交给插画）；句型框拆成"前缀 ＋ 空横线 ＋ 句号"；麦克风搬到贴底动作区。
- 跟读模仿在题型清单里的描述改成不打分的说法：「听一遍，跟着读——开口说了就算完成。」
- 三页版式照开放问答那把尺子统一；《题型任务书-第四批（占位版）》按现在页面的实际做法通读重写（不打分、不给星级、录音就是交卷、结果卡只放鼓励和能带走的内容），末尾 checklist 同步。
