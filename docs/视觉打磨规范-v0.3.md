## 四、熊猫出题（v0.2 新增）

### 1. 核心规则：**一页里只能有一个说话的人**

- 多邻国之所以"像游戏"，靠的是有个角色**一直在场**。我们的角色是熊猫 🐼（原本只在课堂页大恭喜露一次面）。
- 但角色只能有一个：**页面上已经有别的角色、对话气泡或场景图的，熊猫不要出现**——硬加进去就变成"三个人在说话"，更乱。
- 熊猫**只做一件事：站在那儿出题**。不做动作、不说话、不催、不加动效。
- **红线**：熊猫手里**不许拿任何跟答案有关的东西**（茶杯、食物、书本……），那等于把答案画在题面上。

### 2. 出场清单

| 情况 | 页面 |
| --- | --- |
| **出场**（纯文字、没有别的角色或图） | 快速选择、句子排序、补全句子、拼字/组词、找错误/改错 |
| **出场（按同一规则延伸，做之前再确认一次）** | 分类归组、拼音—汉字—含义匹配、课堂投票 |
| **不出场**（已经有人或有图） | 对话补全、情景选择、看图单选、图片—词语连线、连线配对、记忆翻牌、看图说话 |
| **待定** | 听音选图/选词、跟读模仿、开放问答（三个语音占位页；等音频/麦克风形态定了再定，占位期间可以不出场） |

### 3. 版面（照抄样板页）

- 结构：`.choice-stem` 变成一行——左 `.choice-avatar` + 右 `.choice-question-plate`（里面是拼音行 + 题干）。
- 形状：头像**圆形**；题目牌是**普通圆角矩形**，**不许做聊天气泡、不许有尖角或小尾巴**（对话补全那页才是气泡，两者必须长得不一样）。
- **插槽化**：头像表情只写在一处——`--avatar-glyph`（现在是 `"🐼"`）。将来换成自绘熊猫插画时，只替换这一个变量（换成 `background-image`），版面不动。
- 头像占位会让文字区变窄：**上线前用最长的题干试一遍**，窄屏（≤360px）允许把头缩到 40px。

## 五、弹窗规格（v0.2 更新，接口已换）

> 旧写法 `open({ badge, titleZh, titleId, actions })` 已废弃。现在按**档位**自动配色配表情。

```js
AICloudFeedbackModal.open({
  tier: "correct" | "correctFirstTry" | "wrong",
  badge: praise.emoji,      // 句池给的 emoji；不传时按档位兜底（🤩 / 🏆 / 💪）
  titleZh: praise.zh,
  titleId: praise.id,
  actions: [主, 次]          // 第一个自动是 primary-button，其余 secondary-button；次要按钮可用 icon: "↻"
});
```

| 部件 | 规格 |
| --- | --- |
| 弹窗内边距 | 34 / 22 / 26 |
| 徽章 | **98×98 圆**，emoji **56px**，出场 300ms 轻弹（`cubic-bezier(.2,.9,.3,1.45)`） |
| 标题 | **36px / 900 / `#221A3D`**，下方印尼语小字 |
| 按钮 | 最小高 **54px**，与页面按钮同款；**自带印尼语副行**——返回课堂 / Kembali ke kelas、再练一次 / Coba lagi，公共层按文案自动配，页面不用写（规格见第十三节） |

### 三档配色

| 档位 | 徽章底 | 光晕 | ✦ 星星 |
| --- | --- | --- | --- |
| `correct`（答对） | 暖金 `#FFEFC9` | 14px `rgba(255,196,86,.16)` | 2 颗，金色 `#FFC761` |
| `correctFirstTry`（一次全对） | 暖金 `#FFEFC9` | **22px、更亮更散** `rgba(255,196,86,.18)` | **3 颗**（比普通答对多一颗） |

## 六、大恭喜（v0.3：全屏海报）

- 它是**课堂页自己**的弹层（`classroom.html` 的 `.celebrate-overlay / .celebrate-card`），**不在任何题型页里**，也不许搬到题型页。
- 版式：**全屏紫色海报**（占满整个屏幕，不再是居中的白卡）。
- 组成（自上而下）：
  - 全屏渐紫底 `linear-gradient(165deg,#6c58ff,#4c35e8 58%,#37249e)` ＋ 开场白闪；
  - 常驻飘落礼花 16 片（`celebrateFall`，落满 110vh）＋ 开场两波礼花（熊猫处 14 片 ＋ 左右礼花炮 14 发）；
  - **自绘 SVG 熊猫**（戴粉帽、小耳朵、圆脸、腮红；内联在 `classroom.html`，`clipPath` id = `celebrateHatClip`）＋ 半透明圆底 178px（小屏 `clamp(140px, 30vh, 178px)`），弹入后常驻轻浮动；
  - 大字「全部完成啦！」（44px、白、900）＋ 小字「你真厉害！」＋ 印尼语行「Semua sudah selesai! Kamu hebat!」；
  - 底部**唯一出口**白色按钮 `Mantap!`（68px 高、21px 字、`bottom: 42px`）。
- 已删除（别再搬回来）：旧 emoji 熊猫 🐼、白卡底、**词卡列表**。词卡以后若要回来，另开一轮。
- 按钮**不再共用** `.primary-button`，改为自持 `.celebrate-button`（白底紫字）：**改公共按钮不会再波及大恭喜**（原来的"别改坏"提醒作废）。
- 它的作用是**标上限**：**单题页不许比它更热闹**——题型页不加撒花、不加第二条出口、不加第二个循环动效。
- 样式全部挂在 `.celebrate-*` 名下、限定在这个弹层里，**其他页面不受影响**；以后单题弹窗要升级，也不许追平它。
- **触发口**：三关都完成后回到课堂页，先让三颗星跳完（约 0.9s），再盖上海报；只弹一次（`celebrated` 标记），演示面板和表头「重来一遍」都能把它清掉重演。

## 七、自检三问（交页面之前问自己）

1. **第一眼看哪儿？** 打开页面，视线应先落在"题目 + 选项"，不是角标、也不是演示按钮。
2. **有没有多余的字？** 页面只留事实（题面、选项、对错、正确答案）；长解析、重复说明、客套提示都删。
3. **出口是不是唯一？** 每屏只有一个主动作（提交 / 返回课堂），其余动作降级为次要样式；不要出现两个"抢戏"的按钮。

## 八、红线

- 不放长中文解析、不放纯中文小字、不用"分数 / 排名 / 失败"这类词。
- 紫色 = 信号（选中、可提交），不拿它做装饰。
- 动效按第十二节：**反馈动效** 150–350ms、一次只动一下；**常驻 / 状态动效**只在第十二节给的额度内（每页最多 1 个常驻）。
- 一页里只能有一个说话的人；熊猫手里不拿跟答案有关的东西。

**记录类页面的接法**（投票、语音占位等）：**不传 tier**，用中性底 + 固定句（`收到啦！` / `已提交！`）；徽章表情由页面给（投票用 🗳️）。

**判分页的档位口径**：`attempts` 记在同一页会话里、**「再练一次」不清零**——只有页面第一次提交就全对才是 🏆（`correctFirstTry`），重开后再答对落句池档（`correct`）。

**单题页 / 多件题的口径**（2026-09-21 追加）：`correctFirstTry` 分两个池子，挡位名和 🏆 不变，只是抽到哪一句不同。一屏只有一道题的页面（听音选词、快速选择、看图选择、找错改错、情景选择、情景对话 6 个）调 `draw("correctFirstTry", { single: true })`，走单题池（4 条：一次就对！/ 一下就答对！/ 真准！/ 一眼就对！），句子里不出现"全 / 处 / 都"这类只在多件题成立的字。多件题页面（补全句子、拼字/组词、句子排序、分类归组，以及配对类）**不传 single**，默认仍走原来那三句（含「一次就全对！」「一处都没错！」）。

**配对类的档位口径**（2026-09-20 晚改）：配对页不再各写固定句，改从 `draw("pair", { perfect })` 抽一条——池子＝通用夸夸（所有题型共用）＋配对专属句；「一次就连对！」带 `onlyPerfect` 标记，只有一局没连错过才会进候选。弹窗档位随之走 `correct`（连错过）／`correctFirstTry`（没连错，多一颗 ✦）。句池定稿：通用 6 条（🤩 💥 👍 ✨ 🔥 😎）＋配对专属 2 条（🎉 🏅）。

**后续**：句池已定稿（通用 6 条＋配对专属 2 条，2026-09-20）；句池所有句子一律以"！"结尾；👍 与所有新写的印尼语句一并请懂印尼语的同事过目；全部接完后收尾 README 旧约定，再做整体验收＋测试＋构建。

| 项 | 数值 |
| --- | --- |
| 最小高度 | 64px（≤360px 窄屏 56px） |
| 内边距 | 8px 14px（≤360px 窄屏 6px 12px） |

### 2. 宽度规则（本轮唯一新增，一条解决）

- **`min-width: 66px`**：任何词块不窄于 66px；长词自然变宽；**不逐词特判**。
- 来由：360px 窄屏上词库可用宽 292px、间距 8px，"一行 4 个最小宽度词块"的上限 =（292 − 3×8）÷ 4 = 67px → 取 **66px** 顶格给足。
- 效果：360px 下单字块从 41px 撑到 66px，与最窄双字块（约 68px）基本齐平（差约 2px）。
- **拼音不许换行**：词块不会被压到比内容更窄；禁止用"等宽格子"把长拼音词压出两行小字（见预览④）。
- **例外**：标点等无拼音的符号块（找错改错里的"。"）宽度不受 66px 约束，其余项照规格。

## 十二、动态（童趣动效）规格（2026-09-20 定稿）

> **适用**：学生端所有页面（16 个题型页 + 连线 / 翻牌 + 课堂页）。
> **目的**：让页面"有童趣、像活的"，同时不打扰作答、不抢弹窗的戏。
> **数值来源**：2026-09-20 盘点各页已有动效后定的档位；新页面照这份写，不再逐页发挥。

### 1. 三类动效，三种额度

| 类型 | 什么时候动 | 时长 / 周期 | 额度 |
| --- | --- | --- | --- |
| **反馈动效**（一次性） | 作答那一下：选中弹一下、答对弹一下、答错抖一下、反馈条滑入 | 沿用现有变量：按下 `--dur-press` .15s / 入场 `--dur-enter` .26s / 弹入 `--dur-pop` .3s / 抖动 .35s；**不循环** | 不限（都是短动作） |
| **状态动效**（进行中循环） | 只有"正在进行"才有：播放中、录音中、识别中 | 0.7–1.2s 循环；**状态一结束立刻停** | 同屏最多一组（脉冲＋假波形算一组） |
| **常驻动效**（静止时循环） | 学生还没作答、页面静止时的"活气"：角色轻轻动（看图单选的猫）、就绪框呼吸、课堂页卡面慢动 | 角色类 / 卡面类 2.5–5s；指引类 1–1.8s；一律 `ease-in-out` | **每页最多 1 个**（角色、指引、卡面三选一）；唯一豁免＝课堂页大恭喜（见第六节） |

### 2. 幅度上限（别做成"跳跳糖"）

| 档 | 幅度 |
| --- | --- |
| 常驻 · 角色（看图单选那只猫） | 旋转 ≤6°、缩放 ≤1.06、位移 ≤4px |
| 常驻 · 课堂页卡面（慢速，产品拍板"一直在动、慢慢动"） | 周期 3–5s；幅度取角色档一半以内：旋转 ≤2°、缩放 ≤1.03、位移 ≤3px |
| 常驻 · 指引（就绪框呼吸等） | 光圈扩张 ≤4px |
| 状态动效（麦克风 / 播放图标的脉冲） | 缩放 ≤1.18，只限"进行中" |

### 3. 硬规矩

1. **只动 `transform` / `opacity` / `box-shadow`**；不动宽高、位置、`filter`（避免卡顿）。
2. **不抢戏**：题型页提交后常驻动效停住；弹层出现时页面里不再有循环动效。
3. **反馈动效允许"角色呼应"**：答对时角色做一次动作（如猫猫头跳一下）——≤0.5s、一次性、**跳之前先把常驻动效停住**、**答错不做得意动作**（抖动已经给了选项，角色再抖像嘲笑）。
4. **动效不许延迟可操作性**：不能出现"等动画播完才能点"。
5. **无障碍**：公共层 `styles.css` 已有全局"系统开启减弱动态效果 → 动画几乎全停"的兜底，页面**不用**各自再写一份；但**动效不能是唯一的信息载体**（静止时也要看得懂）。
6. **红线承接第八节**：单题不撒花（撒花只留课堂页大恭喜）、不加音效、不加自动播放的强调文字。

### 4. 目前已有的循环动效清单（别重复加、别加第二个）

| 页面 | 动效 | 周期 | 归属 |
| --- | --- | --- | --- |
| 看图单选 `interaction-picture` | 图里角色轻轻摇摆 `pictureSway` | 3.4s | **常驻 · 角色** |
| 分类归组 `interaction-category` | "已就绪"类别框呼吸 `categoryGroupBreathe` | 1.6s | **常驻 · 指引** |
| 课堂页 `classroom`（闯关版，样式在 `classroom.css`） | 关卡卡面里的装饰图慢速浮动 `clsFloat`（三关共用一套，第 2 关延迟半周期） | 4.4s | **常驻 · 卡面** |
| 课堂页三颗星 | 亮星弹入 `starPop` ＋ 一道白光扫过 `starShine`（`.cls-star.is-on` 时各播一次） | 0.55s / 0.58s×2 | 反馈（一次性） |
| 课堂页大恭喜 `classroom`（全屏海报弹层，只在下课那一刻出现） | 撒花 `celebrateFall` ×16 ＋ 熊猫轻浮动 `celebrateFloat` | 3s / 3.5s | **常驻 · 庆祝（豁免：允许两个循环）** |
| 听音 `interaction-listening` | 播放中图标脉冲 `listeningPulse`（`.is-playing` 才有） | 1s | 状态 · 播放中 |
| 跟读 `interaction-read-aloud` | 识别中按钮脉冲 `readAloudWait`（`.is-recognizing`）＋ 录音假波形 `readAloudWave` | 1s / 0.9s | 状态 · 录音 / 识别 |
| 看图说话 `interaction-picture-talk` | 录音脉冲 `pictureTalkMicPulse`（录音 1s / 识别 .7s）＋ 假波形 `pictureTalkWave` | 1s/.7s / 0.9s | 状态 · 录音 / 识别 |
| 开放问答 `interaction-open-qa` | 录音 / 识别脉冲 `openqaPulse`（`.is-recording` / `.is-busy`）＋ 假波形 `openqaWave` | 1s / 0.9s | 状态 · 录音 / 识别 |
| 公共弹窗 `styles.css` | 徽章弹入 `modalBadgePop` ＋ 星光淡入 `modalSparkIn` | — | 反馈（一次性） |

### 5. 命名

`页面前缀 + 动作` 小驼峰（`pictureSway` / `categoryGroupBreathe` / `listeningPulse`）；公共层的写进 `styles.css`，页面的写在自己那份 CSS 里。

## 十三、双语按钮规格（2026-09-20 定稿）

> **适用范围**：学生要按的按钮——题型页的提交 / 重置键、公共弹窗的两个标准按钮。
> 演示控件（右下角两个悬浮按钮、演示题目切换、假手机状态栏）不在内，老师端按钮不在内。
> **为什么**：印尼学生读不懂中文。印尼语副行是他们唯一能读懂的指令，所以按钮一律"中文主词 + 一行印尼语小字"。

### 1. 长相（照这个抄）

- 两行居中、间距 1px、行高 1.15：第一行中文主词（跟按钮字号一致），第二行印尼语小字 **11px / 800 / 透明度 .85**；
- 其余（颜色、厚度、圆角、最小高、按下反馈）跟 `.primary-button` / `.secondary-button` 完全一样——**不许因为多了一行就改按钮尺寸口径**；
- 副行不是装饰：**有副行的按钮，主词和副行必须成对存在**，不许只留中文或只留印尼语。

### 2. 全站口径表（照抄，别自己发挥）

| 场景 | 中文主词 | 印尼语副行 |
| --- | --- | --- |
| 判分页提交键 | 提交 | Kirim |
| 判分页清空键 | 重置 | Ulangi |
| 提交后灰态（同一颗按钮原地变） | 已提交 | Terkirim |
| 弹窗主按钮 | 返回课堂 | Kembali ke kelas |
| 弹窗次按钮 | 再练一次 | Coba lagi |

- "已提交"只是同一颗按钮变灰、变字、不可点，**位置不动、不消失**。

### 3. 怎么写（两种，别混）

- **页面按钮**：HTML 里一颗按钮里放两个 span（主词 + `.btn-id`），按钮加 `btn-stacked`；JS 切三态时只改这两个 span 的文字（`setText` / `textContent`），**不要整体替换按钮的 textContent**（会连副行一起弄丢）。
- **弹窗按钮**：不用写。公共层 `shared/feedback-modal.js` 按按钮文案自动补副行（"返回课堂 / 再练一次"两个标准动作内置）；要单独覆盖时传 `subLabel`。

### 4. 铺开状态（2026-09-20）

- 11 个判分页（快速选择 / 句子排序 / 补全句子 / 看图单选 / 情景选择 / 对话补全 / 课堂投票 / 分类归组 / 拼字组词 / 找错改错 / 听音选词）✅；
- 公共弹窗 ✅（一处改、18 页覆盖）；
- 配对类页面（连线 / 翻牌 / 图片—词语连线 / 拼音匹配）与三页语音题**没有提交键**，不适用。

### 5. 红线

1. 不改按钮颜色、厚度、位置、启用 / 禁用逻辑；
2. 印尼语文案是"学生唯一能读懂的字"，改字（Kirim / Ulangi / Terkirim / Kembali ke kelas / Coba lagi 等）要请懂印尼语的同事过目；
3. 副行字号全站只有 **11px** 一个值（分类归组原来 9.5px，已并到 11px）。
